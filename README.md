# 百合命运观察者 · Lily Fate Observer

一个用 **原生 HTML / CSS / JavaScript** 实现的**百合叙事桌游**：玩家扮演不被看见的「命运观察者」，
秘密选定主推 CP，用事件卡与竞价暗中推动 6 名少女之间**双向独立**的好感，走完 12 个学期后结算结局。
支持 **单机（AI 机器人）** 与 **联机（最多 8 人）**。

- 运行环境：任意现代浏览器（Chrome / Edge / Firefox）。**无需构建、无需登录、无需联网即可单机游玩。**
- 联机需要一个轻量房间服务器（Node.js，零依赖）。
- 许可：MIT（见 [LICENSE](LICENSE)）。

---

## 一、这个项目解决什么问题

很多「叙事向桌游 / galgame」要么只能单机、要么联机配置繁琐，且**文本与美术被写死在代码里，改动门槛高**。
本项目把三个痛点拆开解决：

1. **想联机，但不想搭复杂后端** —— 内置一个**零依赖的 Node WebSocket 房间服务器**，用房主权威 + 状态快照同步，
   浏览器打开即玩，最多 8 人。
2. **想改剧情/数值，但不会写代码** —— 所有文本（角色、卡牌、旁白、界面）都是 `content/*.txt` 纯文本，
   用记事本改完，双击脚本自动生效；卡牌剧情还**按角色性格差异化**（同一张卡，不同角色写法不同）。
3. **想换美术，但讨厌改工程** —— 图片/音频用**同名文件覆盖**即可替换，头像会自动裁成方形、平滑缩放。

同时它本身是一款完整的桌游：**双向好感矩阵、控制点竞价、秘密干扰告白、四类结局**。

## 二、主要功能

### 玩法
- **6 名固定少女**：星见澪 / 白石灯 / 雨宫雫 / 神代纱织 / 森川苺 / 莲见悠，各有偏好、雷点、秘密。
- **双向独立好感 0~5**：A→B 与 B→A 分开计算。
- **12 个学期（3 章）**，每学期：**选事件卡 → 竞价争夺主导权 → 结算 → 剧情 → 小结**。
- **事件卡**：日常（搭话 / 一起放学 / 共享午餐 / 安静陪伴 / 送小礼物）、
  危机（流言误会 / 受伤照料 / 撞见秘密 / 吃醋疏远）、高阶（告白判定）。
- **偏好/雷点**：命中角色偏好加好感，命中雷点减好感。
- **告白判定**：双向好感 ≥ 4 才可能成功；**角色秘密会额外提高失败率**，好感达标也可能失败。
- **秘密为隐藏条件**：开局不显示，需在剧情中「撞见秘密」或告白受挫后才揭晓。
- **四类结局**：双向奔赴 / 三角羁绊 / 单向暗恋 / 挚友；结算公开所有人目标与得分。

### 交互与表现
- **步骤向导**：步骤条 + 大字引导，点选式选卡与选目标（A 主动方 / B 对象），实时效果预览。
- **序章演出**：进入对局后逐段介绍世界观与 6 名少女（介绍到谁就高亮她的面板），读完再选主推 CP。
- **叙事打字机**、**粒子特效**（爱心/墨点/星光）、**合成或真实音效**、优雅的排版。
- **角色图鉴**（页内全屏，左侧完整立绘）、关系观察矩阵、暂停、存档（localStorage）。

### 联机（最多 8 人 · 房主权威）
- **房间码**建房/加入、**玩家名**（自行输入、禁止重名）、**在线人数**实时显示、掉线更新。
- **聊天**（大厅 + 对局内）、**表情**、玩家列表、**房主权限**（开始对局 / 加机器人 / 踢人）。
- **全员到齐才推进**：选牌全体选完、竞价全体锁定、剧情/小结**全员点「继续」**才进入下一步。
- 房主权威广播状态快照；**秘密 CP 目标不进快照**，结局各自公开。

---

### 联机（简化版：部署一次，发个链接大家就能玩）

**关键点：服务器会同时托管「游戏网页」，所以只要部署一次、把网址发给大家，玩家打开链接即可 —— 无需安装、无需填服务器地址。**

**推荐：一键部署到 Render（免费）**

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/miaom4702-art/lily-fate-observer)

1. 点上面的按钮（或用 Render 连接本仓库）→ 按提示创建 **Web Service**。
2. 部署完成得到一个网址，例如 `https://lily-fate-server.onrender.com`。
3. **把这个网址发给朋友**，大家用浏览器打开**同一个网址**。
4. 房主「联机对战 → 创建房间」，其他人输入同一**房间码**「加入房间」即可。

> 当网页来自 `http(s)://`（即通过服务器打开）时，客户端会**自动连接同一个服务器**，「服务器」一栏会自动隐藏 —— 玩家只需填「名字 + 房间码」。

**自己在同一 WiFi 玩（更简单，不部署）**
1. 房主双击 `启动服务器.bat`（需装 Node.js）。
2. 房主浏览器打开 `http://localhost:8787`（服务器已托管游戏网页）。
3. 同一 WiFi 的朋友打开 `http://房主内网IP:8787`。
4. 创建/加入房间即可。

**其它方式**
- Railway / Fly.io / Glitch / Replit：启动命令 `node server/server.js`，监听 `PORT`。
- 自建 VPS：`node server/server.js`，设 `TLS_CERT`/`TLS_KEY` 即支持 `wss://`。
- 想让大家「双击 index.html 也能连某个固定服务器」：把你部署的地址填进根目录 **`config.js`** 的 `server` 字段即可。

## 三、安装方法

### 单机（最简单）
1. 安装任意现代浏览器。
2. 下载本项目（`git clone` 或下载 ZIP 解压）。
3. **双击 `index.html`** 即可开玩（无需服务器、无需构建）。

> 若浏览器对本地文件限制较严，可用本地服务器：
> ```bash
> python -m http.server 8000     # 或 npx serve .
> # 浏览器打开 http://localhost:8000
> ```

### 联机（额外需要 Node.js）
1. 安装 **Node.js ≥ 18**。
2. 无需 `npm install`（服务器零依赖）。
3. 双击根目录 **`启动服务器.bat`**（等价于 `node server/server.js`，默认端口 `8787`），保持窗口开启。

### 修改文本 / 替换素材（可选）
- 文本：编辑 `content/*.txt`，然后双击 **`启动游戏.bat`**（或 `tools\更新文本.bat`）。
- 素材：把图片/音频放进 `tools\素材放入区\`，双击 `tools\应用放入的素材.bat`。详见 `tools\素材替换说明.txt`。

## 四、使用方法

### 单机
1. 双击 `index.html` → 标题画面。
2. **开始新游戏** → 填**玩家名**、选 **AI 对手数** → **开始对局**。
3. 进入**序章**：逐段阅读（介绍到某位少女时她左侧面板会高亮）→ 点「继续」。
4. 序章结束 → **选定你的秘密主推 CP**（点两位少女）→ 确认。
5. 每学期按**步骤条**操作：**① 选事件卡 → ② 选目标(A/B) → ③ 竞价 → ④ 剧情 → ⑤ 小结**。
6. 12 学期后进入**结局**：故事复盘、公开目标与得分、评分与感想。

### 联机
1. 房主先双击 **`启动服务器.bat`**。
2. 各玩家打开 `index.html` → **联机对战** → 填 **玩家名**、**服务器地址**（默认 `ws://localhost:8787`，跨机填房主内网 IP）。
3. **房主**：填/随机**房间码** → **创建房间**；**其他玩家**：输入同一房间码 → **加入房间**。
4. 每人选 **主推 A/B**（本地秘密）。房主可 **+机器人**、**踢人**，点 **开始对局**。
5. 对局中：右侧 **聊天/表情**，顶栏 **在线人数**；**所有人操作完**才推进。

## 五、输入 / 输出示例

### 1）游戏内（输入 = 玩家操作，输出 = 叙事与数值）
**输入**：第 1 学期，玩家选择事件卡「送小礼物」，指定 **A = 白石灯（主动）**、**B = 星见澪（对象）**，
并在竞价中以 3 点控制点胜出。

**输出（叙事区 + 好感变化）**：
```
〔观察者 以 3 点主导〕白石灯把用手帕包好的礼物递过去，只说了两个字：「给你。」
星见澪接过时指尖一颤，把包装纸叠得整整齐齐。
其实那家店，是白石灯特意绕了两站路才找到的。

白石灯→星见澪 好感 +2（现 3）　星见澪→白石灯 好感 +1（现 2）
```
> 说明：剧情由「主动方性格行动 + 对象性格反应 + 随机尾句」拼成，因此同样一张卡、不同角色组合文案不同。

**输入**：某学期用「告白判定」卡，A = 白石灯、B = 星见澪，双向好感达标但触发了澪的秘密。

**输出**：
```
〔观察者 主导〕白石灯直视着星见澪的眼睛，一字一句毫不含糊：「我喜欢你。」
星见澪怔了很久，睫毛颤了颤，却往后退了半步。
（你窥见了 星见澪 的秘密：害怕高强度亲密告白。即使好感很高，也会下意识退缩，告白判定可能失败。）
```

### 2）修改文本（输入 = 纯文本，输出 = 游戏内变化）
**输入**：编辑 `content/cards.txt` 中「搭话」的某一条剧情：
```
出手 mio: 「……早上好。」{A}的声音很轻，像是在心里排练过很多遍。
```
**操作**：双击 `启动游戏.bat` → 浏览器 `Ctrl+F5`。
**输出**：游戏中星见澪主动「搭话」时，会显示刚改写的这句。

### 3）联机（输入 = 房间码/名字，输出 = 同步状态）
**输入**：房主建房 `ROOM1`，玩家名 `小明`；玩家2 用同一房间码、名字 `小红` 加入。
**输出**：两人玩家列表出现「小明(房主) / 小红」，在线人数 `2 / 8`；房主点开始后两人同时进入序章/对局，
状态实时同步；若玩家2 想用名字 `小明`，服务器会拒绝并提示「名字「小明」已被占用，请换一个」。

```

## 七、技术栈

- 原生 **HTML / CSS / JavaScript**（无框架、无构建步骤）。
- **Web Audio** 合成音效（可替换为真实音频文件）。
- **Canvas** 粒子特效。
- **Node.js** 零依赖 WebSocket 房间服务器（手写握手与帧编解码）。
- 数据驱动的纯文本内容管线（`content/*.txt` → `content/generated.js`）。

## 八、隐私与安全

- 不含任何 API Key / 令牌 / 个人隐私信息；联机为**本地自建服务器**，不上传任何数据到第三方。
- 秘密 CP 目标**仅存本地**，不进入网络快照。
