# ============================================================
# 事件卡库（纯文本）
# 每张卡以「# 卡名」开头。字段：
#   id / 类型 / 消耗 / 目标 / 标签 / 效果 / 说明
#   类型：日常 / 危机 / 高阶
#   效果："A>B+1, B>A+1"  A=主动方(先选)，B=对象(后选)，+/-为好感变化；空则不改变
#
# 剧情写法（按角色性格差异化）：
#   出手 角色id: 主动方(A)依照她自己性格的行动描写
#   反应 角色id: 对象(B)依照她自己性格的反应描写
#   尾句: 收尾句（可写多行，随机选一句）
#   → 游戏会把「A的出手 + B的反应 + 尾句」拼成一段完整剧情。
#   角色 id：mio 星见澪 / akari 白石灯 / shizuku 雨宫雫 / saori 神代纱织 / ichigo 森川苺 / yuu 莲见悠
#   占位符：{A}=主动方  {B}=对象
# ============================================================
