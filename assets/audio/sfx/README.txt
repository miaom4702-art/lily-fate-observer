音效目录（放在这里的音效会被自动使用，找不到才用内置合成音）
════════════════════════════════════════════════════
把文件命名为 <名称>.<ogg|mp3|wav|m4a> 放到本文件夹即可，例如 click.mp3。

游戏用到的音效名称（按需提供，缺哪个用哪个合成音）：
  click        点击按钮
  hover        悬停（可选）
  card         翻牌 / 出牌
  bid          加价
  lock         锁定出价 / 提交
  reveal       秘密揭晓
  confessOk    告白成功
  confessFail  告白失败
  round        回合开始
  emote        表情
  vote         投票
  win          结局胜利
  lose         结局失败
  pause        暂停
  resume       恢复
  page         页面切换
  error        错误提示
  coin         加分 / 获得
  confirm      确认

关于 Minecraft 音效
────────────────────
Minecraft 的音效是 Mojang 的版权素材，不能打包进本项目。
想要「MC 风」的手感，可以到上面网站搜
“pop / wooden click / experience orb / level up / anvil” 等免费音效替代。

BGM 放到 assets/audio/bgm/，命名：theme / library / corridor / rainy.<ogg|mp3>
