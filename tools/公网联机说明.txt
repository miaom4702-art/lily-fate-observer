================================================
 公网联机（不同网络 / 局域网之间对战）
================================================

为什么之前联不了？
  之前的「填房主 IP」方式只对【同一局域网】有效。
  跨网络时，房主在自己路由器后面（NAT），别人无法直接连到他的内网 IP。

正确做法：把【房间服务器】放到公网，所有人连公网地址。

------------------------------------------------
 方案 A：免费云平台部署（推荐，最省事）
------------------------------------------------
本仓库已带部署配置：Dockerfile / render.yaml / Procfile / package.json

以 Render 为例：
  1. 打开 https://render.com ，注册/登录
  2. New → Web Service → 连接本 GitHub 仓库
     （有 render.yaml 会自动识别；没有就手动填：
      启动命令 startCommand = node server/server.js，
      环境变量 PORT = 8787）
  3. 部署完成，得到地址，例如：
        https://lily-fate-server.onrender.com
  4. 所有玩家游戏里「联机对战 → 服务器」填：
        wss://lily-fate-server.onrender.com
     （填 https://… 也行，程序会自动转成 wss://）
  5. 房主创建房间，其他人凭房间码加入 —— 跨网络可玩。

Railway / Fly.io / Glitch / Replit 一样：
  启动命令都是  node server/server.js  ，监听端口 8787（读 PORT 环境变量）。

------------------------------------------------
 方案 B：自己有 VPS（可上 wss）
------------------------------------------------
  在服务器上： node server/server.js
  想用 HTTPS/WSS：设置环境变量 TLS_CERT / TLS_KEY 指向证书文件即可。

------------------------------------------------
 方案 C：内网穿透（临时、快速）
------------------------------------------------
  本机运行： node server/server.js
  另开一个窗口运行（需已安装 cloudflared）：
      cloudflared tunnel --url http://localhost:8787
  它会给出一个 https://xxxx.trycloudflare.com 地址，
  玩家填 wss://xxxx.trycloudflare.com 即可。
  （ngrok 同理： ngrok http 8787）

------------------------------------------------
 小结
------------------------------------------------
  同一局域网：填 ws://房主内网IP:8787 即可。
  跨网络：      需要一个公网可达的服务器地址（wss://…）。
