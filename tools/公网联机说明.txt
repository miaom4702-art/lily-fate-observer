================================================
 联机超简单版：部署一次，发个链接，大家就能玩
================================================

好消息：服务器会【同时托管游戏网页】。
所以只要有人部署一次，把网址发给大家，玩家打开链接即可 ——
不用安装东西、不用填服务器地址，只填【名字 + 房间码】。

------------------------------------------------
 推荐做法（免费，5 分钟）
------------------------------------------------
1. 把这个仓库放上 GitHub（已放好就是它）。
2. 打开 https://render.com/deploy?repo=https://github.com/miaom4702-art/lily-fate-observer
   （或 Render 里 New → Web Service → 选本仓库，会自动识别 render.yaml）
3. 等它部署完，得到网址，例如：
        https://lily-fate-server.onrender.com
4. 把这个网址发到群里。所有人用浏览器打开【同一个网址】。
5. 房主点「联机对战 → 创建房间」，其他人输入【房间码 → 加入房间】。
   —— 网页是 http(s) 打开的，客户端会自动连同一个服务器，
      「服务器」那一栏会自动隐藏，玩家完全不用管。

------------------------------------------------
 同一 WiFi 玩（更简单，不部署）
------------------------------------------------
   房主：双击「启动服务器.bat」（需装 Node.js）
         浏览器打开  http://localhost:8787
   朋友：浏览器打开  http://房主内网IP:8787
   然后创建/加入房间。

------------------------------------------------
 其它
------------------------------------------------
   Railway / Fly.io / Glitch / Replit：启动命令 node server/server.js，监听 PORT。
   自建 VPS：设 TLS_CERT / TLS_KEY 环境变量即支持 wss://。
   想让「双击 index.html」也连固定服务器：
       把部署地址填进根目录 config.js 里的 server 字段。

   判断是否公网可玩很简单：
       把网址发给不在同一网络的朋友，他能打开=能一起玩。
